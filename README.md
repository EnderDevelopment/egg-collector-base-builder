# Egg Shell Collection Game

A Roblox game where players collect egg shells and combine them in their base. This game allows players to gather egg shells by touching them in the workspace and combine them in their base to achieve certain goals or rewards.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `CollectEggShells.server.lua` script in the ServerScriptService.
5. Place the `CombineEggShells.server.lua` script in the ServerScriptService.
6. Ensure the egg shells are placed in the workspace under a folder named "EggShells".

## Use

1. Players can collect egg shells by touching them in the workspace.
2. Players can combine egg shells in their base by triggering the combine event.
